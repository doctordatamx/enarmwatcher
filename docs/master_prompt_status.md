# Auditoría de cumplimiento del prompt maestro y 11 TER

Esta matriz separa implementación comprobable, limitación de evidencia y bloqueo externo. No declara terminado todo el programa nacional de investigación por tener páginas o muchos años.

| Área | Implementado | Pendiente / límite |
|---|---|---|
| Fuentes y auditoría | 23 reportes académicos, 3 matrices receptoras, 5 listados de sedes, 4 tablas de umbrales; originales y hashes | Académicos 2024–2026 y oferta anterior a2023 no incorporados; auditoría no exhaustiva de todo lo público |
| Arquitectura | Python, JSON por módulo, DuckDB y Parquet Zstandard, React/TS/Vite/ECharts | No backend permanente; no API privada |
| Marca | Isotipo, logos claro/oscuro/monocromo, favicon, PNG192/512, OpenGraph y manifest | Sin auditoría de marca externa |
| Navegación e inicio | Inicio, panorama, procedencia, especialidades, receptoras, sedes, comparadores, atlas, ciencia de datos, predicción, explorador, reportes, métodos, fuentes; búsqueda global | Rutas hash bajo subruta Pages |
| Panorama nacional | Sustentantes, seleccionados, tasas, medias ponderadas cuando procede, tabla/exportación | Agregados de filas reportadas, no conteo de personas únicas; no mezcla de medianas o escalas |
| Universidades | Perfiles, entidad fuente, historia, tamaños, tasas, Wilson, comparación nacional, filtro volumen, comparadorhasta 5 | 450 claves exactas no equivalen a450 universidades distintas; equivalencias históricas no revisadas no se fusionan |
| Rankings | Orden por tasa/media/volumen por edición, denominadores, percentiles/rangos precomputados y empates | Movilidad longitudinal y rankings causales bloqueados |
| Specialty Intelligence | Entregado previamente y conectado a oferta receptora por clave de especialidad | Comparabilidad temporal y denominadores de demanda pendientes |
| Receptoras | Perfiles de filas institucionales, oferta por especialidad, tres snapshots, concentración, diversidad, LQ, correspondencias y clustering exploratorio | Oferta no equivale a asignación u ocupación; jerarquías no documentadas no se inventan |
| Sedes | 2,544 códigos de oferta2025, perfiles por nombre/institución/entidad, aval, sede/subsede separados | CLUES, municipio, coordenadas y condiciones laborales no vinculados |
| Atlas |32 estados; procedencia y oferta receptora separadas; filtros y SVG/CSV | Sin puntos hospitalarios aproximados ni tasas poblacionales sin denominadores |
| Laboratorio | Pearson/Spearman por edición, concentración, Lorenz/Gini/HHI, Pareto, descomposición geográfica, beta-binomial; motor longitudinal de especialidades | Convergencia/movilidad institucional longitudinal, PCA/cluster longitudinal académico y efectos causales no publicados por comparabilidad pendiente |
| Predicción | Motor temporal naive/Theil–Sen, validación, intervalos, restricciones; simulador hipotético | Pronósticos oficiales/nacionales/receptores desactivados por evidencia insuficiente |
| Reportes | PDF directo, HTML autónomo, CSV, JSON; PNG en gráficos, SVG en atlas | Reportes no incluyen modelos bloqueados ni conclusiones no sustentadas |
| Script R adjunto | Ausencia documentada | `reporte_ejecutivo_udem_enarm_codigo_completo(1).R` no proporcionado en los adjuntos disponibles; equivalencias numéricas con ese script no verificables |
| Actualización | Monitor semanal, hashes, descubrimiento, reporte de candidatos; CI reconstruye/valida antes de publicar | Cambios de formato/categoría requieren revisión; no promoción silenciosa de candidatos no auditados |
| Accesibilidad/responsividad | Etiquetas, foco, tablas, controles táctiles, temas, movimiento reducido; revisión visual | Sin certificación WCAG ni puntuación Lighthouse declarada |
| Publicación | Workflow de Pages y artefacto estático | GitHub devuelve Repository not found. Hace falta acceso autenticado al repositorio objetivo y activar Pages; URL pública no verificada |
| Gobernanza | Metodología, diccionarios, fuentes, changelog, guía de contribución y licencia de código separada de fuentes | Canal GitHub requiere repositorio accesible |

Las tareas bloqueadas por fuente no se sustituyen con resultados ficticios. Las tareas dependientes de GitHub no se declaran publicadas.
